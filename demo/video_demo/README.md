# EvidenceCoder 视频演示项目

这是一个只使用 Python 标准库的可复现微型项目。项目故意在免运费临界值处保留一个错误：

- 业务规则：订单金额大于或等于 100 元时免运费；
- 修复前：100 元订单被收取 8 元运费，结算总额错误地变成 108 元；
- 修复后：100 元订单运费为 0 元，结算总额为 100 元；
- 修复范围：只需对 `shipping.py` 做一个最小边界条件修改；
- 验收标准：3 项测试全部通过，且测试文件保持不变。

初始状态可以手动验证：

```powershell
python -m unittest discover -s tests -v
```

预期初始结果为 3 项测试中 1 项失败。不要先手工修复；让 EvidenceCoder 读取
`VIDEO_TASK.txt` 并完成任务。
